# EmployeeManagementSystem

EmployeeManagementSystem is a SQL Server script for creating and loading an employee management database. It models employee, department, and organizational data for local reporting and query practice.

## Features

- SQL Server table creation and seed data
- Employee and department-oriented relational design
- Single executable setup script

## Tech Stack

- Microsoft SQL Server
- T-SQL

## Getting Started

Open `EmployeeManagementSystem.sql` in SQL Server Management Studio or Azure Data Studio and run it against a SQL Server instance where you have database creation permissions.

## Project Structure

- `EmployeeManagementSystem.sql`: database setup and seed script
